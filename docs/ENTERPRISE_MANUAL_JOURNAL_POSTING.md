# 企业级手工总账凭证过账治理

版权所有 © 2026 上海如静知华信息科技有限公司（[知华科技官网](https://www.zhuatech.cn/)）。

## 适用范围

用于非自动来源的调整、暂估、预提、重分类和期末手工凭证，防止绕过总账期间、核算维度、附件、审批与职责分离控制。

## 强制控制

- 期间开放、借贷平衡、科目可用，成本中心、项目及组织维度完整。
- 来源附件可验证，重复凭证检查通过，内部往来双方配平。
- 税码、大额或非常规凭证完成分级审批，制证与审批职责分离。
- 外币汇率版本必须锁定，编制、复核、审批和附件证据链完整。
- 自动冲回、过账通知与归档包作为待复核行动项。

## 接口与决策

`POST /api/enterprise/erp/manual-journal-posting`

返回 `POST`、`REVIEW` 或 `BLOCKED` 及可解释原因。税务、资金和外部总账系统仅预留标准适配方式，由使用方自行配置。
